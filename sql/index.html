Arsenal

Install a database

The heist console ran SQLite inside your browser. To keep practising you need a database on your own computer. Start with SQLite, since it is the engine you just used and takes about two minutes. Move to PostgreSQL when you want the one most career roadmaps point to.

Best forThe fastest start. One file is one database, and the syntax matches the heist console.
Option A: point and click

  1. Download DB Browser for SQLite

    Get it from sqlitebrowser.org/dl. It runs on Windows, macOS and Linux.

  2. Create the database

    Open the app, click New Database and save it as heist.db. Close the table dialog that appears.

  3. Run the starter script

    Open the Execute SQL tab, paste the starter script from further down, and press the Run button. Save with Write Changes.

Option B: command line

  1. Get the sqlite3 tool

    macOS ships with it. On Ubuntu run the command below. On Windows download the sqlite-tools zip for Windows (x64) from sqlite.org/download, unzip it and open a terminal in that folder.

    sudo apt install sqlite3

  2. Open a database file

    The file is created on first use.

    sqlite3 heist.db
.headers on
.mode column

  3. Paste the starter script, then check

    Type .tables and you should see servers. On macOS, a binary you downloaded may need xattr -d com.apple.quarantine sqlite3 before it runs.

Best forBackend, data and cloud work. A very widely used open-source database, and the one behind the PostgreSQL DBA roadmap.
Windows and macOS

  1. Download the installer

    Open postgresql.org/download/windows and follow it to the EDB installer. On a Mac, use postgresql.org/download/macosx.

  2. Run it with the defaults

    The Windows installer includes the server, pgAdmin and Stack Builder. Set a password for the postgres user and write it down. Keep port 5432. You can skip Stack Builder at the end.

  3. Open pgAdmin 4

    Expand Servers, enter your password, then right-click Databases, choose Create, Database, and name it heist.

  4. Run the starter script

    Select heist, open Tools, Query Tool, paste the script and press F5.

Ubuntu and other Linux

  1. Install and open a prompt

    sudo apt update
sudo apt install postgresql
sudo -u postgres psql

  2. Create and enter the database

    CREATE DATABASE heist;
\c heist

  3. Paste the starter script, then check the version

    SELECT version();
Best forClassic web stacks and a huge amount of existing hosting and tutorials.
Server and Workbench

  1. Open the download page

    Go to dev.mysql.com/downloads/mysql. Pick a version labelled LTS. The page lists 8.4 LTS and 9.7 LTS beside newer releases, and LTS is the steadier choice for learning.

  2. Choose your operating system and install

    On Windows pick the MSI installer and run it. Set a password for the root user, write it down, and keep port 3306.

  3. Add MySQL Workbench

    Download it from dev.mysql.com/downloads/workbench. On Windows it needs .NET Framework 4.5 and the Visual C++ 2019 Redistributable, both listed on that page.

  4. Connect and run

    Open Workbench, click the local connection, enter the root password, paste the lines under Ubuntu, then the starter script, and press the lightning bolt.

Ubuntu and first commands

  1. Linux install

    sudo apt update
sudo apt install mysql-server
sudo mysql

  2. Create the database

    CREATE DATABASE heist;
USE heist;

  3. Check it works

    SELECT VERSION();
Best forOne window for every database. Use it as your front end for SQLite, PostgreSQL and MySQL.

  1. Download DBeaver Community

    It is free and open source for Windows, macOS and Linux. Get it from dbeaver.io/download.

  2. Create a connection

    Click New Database Connection and choose SQLite, PostgreSQL or MySQL. For SQLite, point it at your heist.db file. For the others, enter localhost, the port and the password you set.

  3. Accept the driver download

    The first time you connect, DBeaver may offer to download a driver. Say yes.

  4. Open an editor and run the script

    Press Ctrl+] for a new SQL script, paste the starter script, and run the whole file with Alt+X.

Best forCompanies built on the Microsoft stack. The Developer edition is free for development and testing.

  1. Open the download page

    Go to microsoft.com/sql-server/sql-server-downloads and choose the Developer edition.

  2. Pick how to run it

    The page offers Windows, Linux and a Docker container image. Docker keeps it off your main system, which is handy on a shared laptop.

  3. Connect with a client

    DBeaver works well here too. Choose SQL Server as the connection type.

  4. Mind the dialect

    SQL Server speaks T-SQL. It uses SELECT TOP 5 where the heist console used LIMIT 5.

Starter script. Works in every database above.

A small practice copy of the servers table. The rows are an example and not the exact heist data.

CREATE TABLE servers (
  id INTEGER PRIMARY KEY,
  name VARCHAR(20),
  zone VARCHAR(20),
  status VARCHAR(20)
);

INSERT INTO servers (id, name, zone, status) VALUES
  (1, 'ALPHA-1', 'Restricted', 'online'),
  (2, 'VAULT-7', 'Restricted', 'online'),
  (3, 'BETA-2',  'Internal',   'online'),
  (4, 'GAMMA-9', 'Internal',   'maintenance'),
  (5, 'ECHO-5',  'Public',     'online');

SELECT name, status
FROM servers
WHERE zone = 'Restricted'
ORDER BY name;
