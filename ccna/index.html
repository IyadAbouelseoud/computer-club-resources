Install Cisco Packet Tracer

HexNet Lab runs in your browser. Packet Tracer is the same idea with Cisco's full device library, and it is the simulator Cisco's own courses use. Cisco offers it free through Networking Academy.

Get the installer

  1. Open the official page

    netacad.com/cisco-packet-tracer. Use only this address for the download.

  2. Create a free Networking Academy account

    Use an email you check often and verify it. The same login unlocks Packet Tracer and Cisco's free networking courses.

  3. Follow the sign-up or download button on that page

    Cisco may ask you to enrol in a short free course first. That is normal, and the download is inside the course resources.

  4. Pick the installer for your computer

    Official builds exist for 64-bit Windows, macOS and Ubuntu Linux. The download page lists the current version and minimum system requirements.

Install it

  1. Run the installer

    Double-click the downloaded .exe and accept the licence.

  2. Keep the defaults

    Leave the install folder and the desktop shortcut option as they are, then click Install and Finish.

  3. If Windows shows a warning

    SmartScreen may flag a new installer. Continue only if you downloaded it from netacad.com.

  1. Open the disk image

    Double-click the downloaded .dmg file.

  2. Drag to Applications

    Drag the Packet Tracer icon onto the Applications folder.

  3. First launch

    If macOS blocks the app, right-click it in Applications, choose Open, then confirm.

  1. Open a terminal in your Downloads folder

    Check the exact file name first with ls.

  2. Install the package

    Replace the file name with yours.

    sudo apt update
sudo apt install ./CiscoPacketTracer*.deb

  3. Launch it

    Open Packet Tracer from your applications menu.

Test it

  1. Sign in

    Start Packet Tracer and sign in with the same Networking Academy account.

  2. Rebuild mission 1

    Drag in two PCs and a switch, join them with copper straight-through cables, set 192.168.1.10 and 192.168.1.11 with mask 255.255.255.0, then run ping 192.168.1.11 from PC1's command prompt.

  3. Then take on the bigger one

    Rebuild Mawja HQ in Packet Tracer, save it as a .pkt file and show it to the club. The commands are the same ones you typed in HexNet Lab.

Before you start

  • A 64-bit computer running Windows, macOS or Ubuntu.
  • Around 4 GB of RAM and a couple of GB of free disk space is plenty. Check the download page for the exact current figures.
  • A free Networking Academy account.

Download from netacad.com only

Search results are full of mirror sites and cracked installers. Those can carry malware. The official download is free, so there is no reason to use them.

If something goes wrong

  • Cannot sign in: reset the password from the Networking Academy login page.
  • Installer will not start: it is 64-bit only. Check your operating system version.
  • Download blocked: some campus or office networks filter it. Try your home or mobile connection.

No laptop handy?

Keep practising in HexNet Lab. It runs in any browser, including your phone.

Certification

The CCNA exam

CCNA is Cisco's associate-level networking certification, and the usual first step into a network, support or security role.

Facts from Cisco
Exam
200-301 CCNA, Implementing and Administering Cisco Solutions
Length
120 minutes
Price
US$300, or Cisco Learning Credits
Languages
English, Japanese
Valid for
Three years
Renew by
Passing the current CCNA or any higher Cisco exam, or earning 30 continuing education credits

Pearson VUE test centres and online proctoring are scheduled through Cisco's exam portal. Check the price in your region before you book.

Domain weights

Weights are those of exam version 1.1. Confirm them on the official exam topics page, because Cisco updates the blueprint from time to time.
