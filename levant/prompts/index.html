Gemini prompt library صندوق الدنيا

Everything the Levant booth game can use from Gemini. The game already ships with built-in drawings for all of it, so nothing is blocked: each image you generate simply replaces its built-in version.

How to use
  1. Open a new Gemini chat. Paste the Style lock once as your first message so every image shares one look.
  2. Generate the Box and the Hakawati first. When you like one, attach it as a reference to later prompts ("same style as the attached image").
  3. Items, box and hakawati use a solid pure green #00FF00 background. Don't cut them out yourself: Claude does that in PhotoCraft (see the pipeline below).
  4. Download each image at full size and rename it to the filename shown (for example items/rakweh.png).
  5. Send the raw files to Claude in the chat, or put them in a folder and connect it. Claude runs the finishing pass, converts them to WebP for the web (items items/<id>.webp, scenes scenes/<code>.webp, box and hakawatis <name>.webp; banknote vignettes stay lira/<value>.png for print), updates manifest.json and deploys.

6 · What Claude does in PhotoCraft (so nothing looks AI-generated)

  

    
    
      
  1. Key out the green: Select › Color Range on #00FF00 (fuzziness about 60), delete, then shrink the edge 1 px and remove leftover green spill so there's no glowing halo.
    2. 
      
  2. Lock the palette: Gradient Map adjustment built from the booth colours (basalt › cobalt › red › orange › gold › limestone) at about 30–40% in Color mode. Every image ends up in the same 8-colour family as the game.
    3. 
      
  3. Kill the AI sheen: flatten shiny highlights (Levels on the top 10%), Despeckle to remove the over-smooth "plastic" texture, and a light Median on the over-detailed areas.
    4. 
      
  4. Make it printed: monochrome Add Noise (about 3%) for paper grain, and a Halftone Pattern layer on the shadows at 12–18% Multiply. Then a 1 px red-offset copy of the outline at about 25% Multiply for real riso misregistration.
    5. 
      
  5. Export to spec: items as 512×512 transparent PNG, scenes as 2560×1600 JPG (quality 82), box and hakawati as about 1200 px tall transparent PNG, vignettes as 600×600 PNG.
