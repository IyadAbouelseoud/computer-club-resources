Gemini image prompt library

For the kids games (Cave Guardians + Little Programmers Caravan). The games already ship with built-in vector art, so nothing is blocked: every image you add here simply replaces its built-in version.

How to use (5 steps)
  1. Generate Ali Baba (sly) first. Keep the best result and use it as the reference image for every other Ali mood ("keep the exact same character").
  2. Do the same with the two kids and the camel robot, so each character stays consistent across poses.
  3. Use 1:1 square. Every prompt asks for a solid pure green (#00FF00) background. Don't worry about transparency: send me the images as they are and I will cut the green out and wire them in.
  4. Name each file exactly as shown in file (for example ali-sly.png). If you can't rename, send them in order and tell me which is which.
  5. You don't need all of them. Priority: the Ali Baba set, the two kids and the camel robot. The rest are optional polish.

Style rules baked into every prompt: bright children's picture-book cartoon, thick dark outlines, rounded shapes, Arabian-nights palette, friendly (Ali Baba must be goofy and harmless, never scary), no text inside the image.
